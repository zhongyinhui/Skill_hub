# Skill Versioning

本仓库使用语义化版本管理 skill。

## 格式

```text
MAJOR.MINOR.PATCH
```

示例：

```text
1.4.2
```

## 什么时候升 MAJOR

不兼容变化，使用者需要调整原来的用法。

示例：

- skill 的输入格式变了。
- 原有命令、脚本或字段被删除。
- Agent 工作流从“先提问”改成“直接执行”。
- 文件结构变化导致旧安装方式不可用。

## 什么时候升 MINOR

新增能力，但旧用法仍然可用。

示例：

- 新增一个表单类型。
- 新增一个工具脚本。
- 新增示例或模板。
- 增加更明确的场景处理规则。

## 什么时候升 PATCH

修复或优化，不改变能力边界。

示例：

- 修 typo。
- 改善说明文字。
- 修复一个边缘场景。
- 补充缺失说明。

## CHANGELOG 写法

每个版本使用：

```markdown
## 1.2.0 - 2026-05-06

### Added

- 新增合同类表单示例。

### Changed

- 优化字段缺失时的提问方式。

### Fixed

- 修复金额字段示例不一致的问题。
```

没有内容的小节可以省略。
