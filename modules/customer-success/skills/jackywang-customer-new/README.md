# Jackywang Customer New

这是一个面向客户成功新人的跟进副驾驶 skill，适用于 Jacky Wang 在处理客户会议、逐字稿、聊天记录、内部交接、客户需求、跟进动作、客户画像、风险提醒、客户回复、内部同步、新人日报和新人周报时使用。

它的目标不是替用户直接承诺客户事项，而是帮助新人客户成功同事把零散客户信息整理成清楚的判断、安全的跟进动作、内部确认清单和可复用的学习沉淀。

## 适用场景

- 客户会议纪要、逐字稿或聊天记录整理。
- 客户需求、隐含诉求和风险点拆解。
- 我方承诺、责任人和时间节点审计。
- 面向客户、内部同事和负责人的跟进话术起草。
- 客户画像增量沉淀。
- 新人日报、周报和述职素材整理。
- 新人业务痛点和学习清单提炼。

## 使用方式

当用户提供客户相关内容，并希望整理下一步跟进、内部确认、客户回复或新人复盘时，使用本 skill。

示例请求：

```text
帮我把这段客户会议逐字稿整理成下一步跟进动作。
帮我判断客户真正关心什么，哪些地方需要内部确认。
帮我写一版发给客户的谨慎回复。
根据今天的客户沟通，帮我写新人日报。
```

## 输出重点

默认输出会覆盖这些内容：

- 当前情况理解。
- 客户真正关心的问题。
- 需求分类和优先级。
- 我方承诺与风险。
- 新人必须确认的问题。
- 下一步动作。
- 可直接发送的话术。
- 客户画像增量。
- 业务痛点和学习清单。
- 新人日报和周报沉淀。

如果用户需要更完整的表格型输出，可参考 `references/output-template.md`。

## 安全边界

- 默认只做分析和草稿，不更新客户档案、CSV、飞书文档、任务系统、Git 或生产规则。
- 只有用户明确要求写回时，才进入真实写回步骤。
- 涉及范围、权益、时间、技术可行性、价格等内容时，先建议内部确认。
- 不把客户期待误写成我方承诺。
- 不在事实未确认时对客户做确定性承诺。
