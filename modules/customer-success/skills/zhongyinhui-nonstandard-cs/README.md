# zhongyinhui-nonstandard-cs

中隐会客户成功（CS）非标技术问题处理 skill，用于帮助 CS 判断客户提出的非标准技术需求是否可做、需要补充哪些信息，以及应该输出什么客户可见材料。

## 定位

这是客户成功模块下的中颗粒 skill，适用于客户问“能不能做”“怎么做”“是否值得做”“要不要交给技术”“能否生成 PDF 方案”等场景。

它不替代技术评审，也不默认承诺中隐会负责定制开发。它的核心价值是把客户问题整理成可判断、可转发、可交付的专业材料。

## 典型输出

- 信息不足时：给 CS 的关键追问清单。
- 绿灯或黄灯时：《技术路线与执行方案》及可渲染 PDF。
- 红灯时：《技术可行性与前瞻评估报告》。
- 面向 CS 的单独沟通话术。

## 使用方式

在当前项目中同步入口后，可用以下方式触发：

```text
使用 $zhongyinhui-nonstandard-cs 评估客户非标技术需求，并生成合适的客户交付物与沟通话术。
```

如果需要生成 PDF，skill 会使用：

```text
scripts/render_deliverable_pdf.py
```

客户交付物应保存到当前项目工作目录下的：

```text
outputs/zhongyinhui-nonstandard-cs/
```

不要把运行产物保存到 skill 目录内部。

## 评审重点

- 是否区分信息不足、可执行路线和不建议直接落地三类结果。
- 是否避免把客户期待误写成中隐会承诺。
- 是否补充成本、权限、数据质量、隐私、速率限制和运行风险。
- 是否把客户 PDF 正文和 CS 沟通话术分开。
- 是否在 API、模型、价格、平台规则等不稳定信息上要求核验当前官方来源。
