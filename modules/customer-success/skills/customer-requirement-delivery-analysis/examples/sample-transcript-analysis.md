# 示例：逐字稿后的需求与交付拆解

## 示例输入

```text
客户：我们现在不是缺工具，是团队每个人都按自己的方式跟客户，资料散在飞书、微信和表格里。
我方：那我们可以先帮你搭一个客户跟进的资料归档和分析流程。
客户：最好能每次开完会就知道客户要什么，下一步谁交付什么，也能看到哪些地方是我们自己没说清楚。
我方：可以，先做一个小范围试点，拿最近三次会议记录跑一下。
```
