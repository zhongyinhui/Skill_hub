# 验收检查清单

用真实逐字稿试跑时，至少检查以下行为：

- 能从原始语料中抽取需求，并为每条需求标证据。
- 能区分明确需求、隐含需求和待确认需求。
- 能区分客户期待和我方明确承诺。
- 能把需求拆成交付物、任务、责任人、时间和风险。
- 能在没有权益清单时标 `权益待确认`，而不是硬判范围内。
- 能输出客户画像增量，并使用 `新增`、`强化`、`修正`、`冲突`、`待确认`、`无变化`。
- 能说明建议写回位置，但不会默认修改客户档案、CSV 或飞书。
- 能列出人工确认点和可进入自进化回流的规则增量。
- `SKILL.md` frontmatter `name` 与目录名一致，且 description 能覆盖用户上传 `.txt`、`.md`、`.docx` 文本材料的触发场景。
