# C-SK04 Customer Progress Risk

这个 skill 用于从 A/B/C 事实中识别客户停滞、高意向、临门一脚、交接和主管介入风险候选。

## 适用场景

- 需要分析客户推进是否停滞。
- 需要识别高意向或临门一脚客户。
- 需要为 C-SK08 主管干预 draft 提供风险候选。

## 使用边界

- 只生成风险候选，不直接创建确认干预。
- 不覆盖 A 线客户阶段、评级或客户主档。
- 结论必须绑定 A/B/C 来源证据，避免无来源判断。

## 评审重点

- 是否清楚说明风险触发原因。
- 是否保留客户、销售、周期和来源引用。
- 是否把“建议主管关注”和“已主管干预”分开。
