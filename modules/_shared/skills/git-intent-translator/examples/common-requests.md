# Common Requests

| Ordinary request | Expected agent behavior |
| --- | --- |
| 保存一下 | Inspect changes, summarize included files, validate, commit |
| 发给同事看看 | Ensure commit exists, push review branch, open or prepare PR |
| 看看我改了什么 | Show status and summarize diff |
| 更新到最新 | Protect local changes, fetch, inspect, then sync safely |
| 发布这个 skill | Validate skill, check version, create or prepare tag |
| 回到之前 | Inspect changed files, ask confirmation before restore |
