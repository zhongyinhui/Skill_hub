# C-SK16 System Health

这个 skill 用于监控 C 线 P0 运行中的字段缺失、来源引用断裂、黑灯失败、权限问题、版本冲突和公共表写入冲突。

## 适用场景

- 需要记录 C 线系统健康问题到 C07。
- 需要区分业务影响和技术影响。
- 需要提出修复建议但不自动修改字段、权限或表结构。

## 使用边界

- 只生成维护记录和修复建议，不自动执行修复。
- 不扩大写入范围，不绕过 C-BL00 调度。
- 不把测试数据异常当作生产事实结论。

## 评审重点

- 是否说明 related_line、related_table 和 related_skill_id。
- 是否清楚区分 business_impact 与 technical_impact。
- 是否避免自动字段创建、权限变更或结构调整。
