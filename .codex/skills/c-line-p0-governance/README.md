# C Line P0 Governance

这个 skill 是销售模块 C 线 P0 阶段的总控入口，用于约束主管治理最小闭环的执行边界、读取顺序和输出责任。

## 适用场景

- 需要执行或复核 C 线 P0 主管治理流程。
- 需要串联 C-BL00、C-SK01、C-SK02、C-SK03、C-SK04、C-SK08、C-SK16。
- 需要确认 P0 只生成事实、摘要、风险候选、主管干预 draft 和系统健康记录。

## 使用边界

- 不执行 P1 训练闭环、D 线权重调整、SOP 发布、产品反馈包或总经办自动提交。
- 不直接改 A/B/D/E 线运行数据，不创建或修改 Feishu/Lark 表结构。
- 主管干预输出默认为 draft，必须由人工主管确认后才成为正式干预。

## 评审重点

- 是否只覆盖 P0 最小闭环。
- 是否保留来源引用和人工确认边界。
- 是否避免把 AI 建议写成已确认业务动作。
