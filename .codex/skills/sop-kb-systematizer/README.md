# SOP KB Systematizer

这是一个跨部门通用 skill，用于把公司 SOP、制度流程、知识库、操作手册和零散文档整理成系统化知识库。

## 适用场景

- 整理公司或部门 SOP。
- 把零散制度、流程说明、会议纪要、培训材料变成知识库。
- 为团队生成可维护的知识库总览 Markdown。
- 生成一个可直接打开的响应式单文件 HTML 知识库。
- 需要用目录树、分类和子页面降低长文阅读压力。

## 默认输出

- 一份 Markdown：用于审阅、留档和持续维护。
- 一个单文件 HTML：内嵌 CSS、JS 和页面数据，适配手机端和电脑端。

HTML 默认采用“单文件 + 虚拟子页面”方式：文件本身只有一个 `.html`，但页面内通过目录树、hash route 或数据驱动渲染实现嵌套式子页面体验。

## 归属模块

归属 `_shared`，因为 SOP 和知识库系统化整理可被客户成功、销售、IP、私域、HR 和管理协作场景共同复用。

如果后续出现强业务专用版本，例如“客户成功交付知识库”“HR 入职 SOP 知识库”或“私域运营 SOP 手册”，建议在对应部门模块中新增专用 skill，并在 README 中说明它与本通用 skill 的边界。

## 审核重点

- 是否保持 skill 名、目录名和 `SKILL.md` frontmatter `name` 一致。
- 是否明确要求输出 Markdown 与单文件 HTML。
- HTML 是否要求响应式、嵌套式子页面、目录树和搜索。
- 是否避免把待确认、推断或冲突材料写成事实。
- 是否能指导 Agent 先做页面地图，再生成正文和 HTML。
- 是否未包含本机路径、密钥、临时日志或具体公司敏感资料。

## Release Notes

初版为轻量文本型 skill，不包含脚本。后续如果团队形成固定 HTML 模板，可以增加 `assets/` 模板文件；如果需要批量转换 Markdown 到 HTML，可以再增加 `scripts/` 工具。
