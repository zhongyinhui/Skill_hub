# C-SK02 Daily Fact Sync

这个 skill 用于把 B 线 active 日记录和黑灯输出同步成 C01 daily_fact，形成 C 线主管治理可以追溯的销售日事实。

## 适用场景

- 需要将 B 线 daily record 映射到销售个人 C01 表。
- 需要把 A/B/D/E 来源引用保留到 C 线事实记录中。
- 需要为后续周期摘要、客户推进风险和主管干预提供事实输入。

## 使用边界

- 只同步 active 且可追溯的事实，不补写无法确认的销售行为。
- 不修改 B 线原始过程记录。
- 不覆盖 A 线客户阶段、评级或完整客户档案。

## 评审重点

- 是否保留来源记录 ID。
- 是否区分日事实与后续分析结论。
- 是否在 C01 索引或真实销售路由缺失时停止生产同步。
