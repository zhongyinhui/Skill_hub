# C-BL00 Controller

这个 skill 用于 C 线 P0 总控调度，负责安排有序任务队列、协调公共治理表写入，并把异常路由到 C07。

## 适用场景

- 需要启动 C 线 P0 流程前进行调度设计。
- 需要避免多个销售黑灯或分析流程并发写入公共治理表。
- 需要把字段、权限、同步或写入冲突记录为 C07 维护事项。

## 使用边界

- C-BL00 不是业务判断 skill，不生成销售评价、客户风险结论或训练建议。
- 不直接修改表结构、权限或其他线路数据。
- 公共表写入必须保留调度来源和异常处理记录。

## 评审重点

- 是否清楚区分调度责任和业务分析责任。
- 是否避免并发写入冲突。
- 是否把异常交给 C07，而不是静默修复。
