# C-SK03 Period Summary

这个 skill 用于基于 C01 daily_fact 生成滚动 7/14/30 天和月度周期摘要，帮助主管识别销售过程趋势。

## 适用场景

- 需要从日事实汇总销售活动、转化、风险和 D/E 使用情况。
- 需要生成可追溯的 rolling 或 monthly summary。
- 需要为客户推进风险、能力诊断或主管关注提供周期输入。

## 使用边界

- 周期摘要只基于已确认 daily_fact，不直接读取或改写 B 线原始记录。
- 不把摘要直接转成处罚、训练结论或正式主管干预。
- 所有汇总都应保留可回查的来源范围。

## 评审重点

- 是否说明 period_start、period_end 和摘要类型。
- 是否保留来源 daily_fact 记录。
- 是否避免把趋势信号夸大为确定归因。
