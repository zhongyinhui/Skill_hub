# C-SK01 Sales C01 Index

这个 skill 用于维护销售个人 C01 表索引，确保销售、主管、权限范围、启用状态和异常路由可以被 P0 流程安全读取。

## 适用场景

- 需要定位销售个人 C01 表路径。
- 需要确认销售和主管映射关系。
- 需要识别缺失索引、权限不足或停用销售的异常情况。

## 使用边界

- 不创建新字段，不改现有表结构。
- 不把测试销售路由当作真实生产销售路由。
- 数据质量异常应记录到 C07 或交由 C-BL00 调度处理。

## 评审重点

- 是否保留 C01 表路径和权限范围。
- 是否清楚标记 active/inactive 状态。
- 是否避免在索引不完整时继续执行下游事实同步。
