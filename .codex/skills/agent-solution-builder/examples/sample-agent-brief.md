# 示例：模糊需求转提示词

用户输入：

```text
客户叫星河教育，他们想做一个招生顾问智能体。能根据家长咨询内容判断孩子年级、预算、意向校区，然后生成跟进话术和下一步任务。
```

期望输出：只输出一个可直接使用的智能体提示词，例如包含：

- 角色：招生顾问辅助智能体。
- 目标：从家长咨询中抽取线索、判断意向、生成跟进话术和任务。
- 输入理解：年级、预算、校区、课程兴趣、时间、家长顾虑、缺失字段。
- 工作流程：信息抽取、意向分级、需求判断、话术生成、任务生成、人工确认。
- 输出要求：线索摘要、意向等级、跟进话术、下一步任务、待确认问题。
- 边界：不承诺录取结果，不虚构课程价格，不自动写入 CRM。
