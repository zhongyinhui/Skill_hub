# Agent Solution Builder

这是一个跨部门通用 skill，用于把客户的模糊智能体需求直接整理成可用提示词。

## 适用场景

- 用户给出客户名称和粗略需求，希望直接拿到智能体提示词。
- 用户提供聊天记录、会议纪要、SOP、表格字段或业务流程，希望转成 agent prompt。
- 用户不想填写需求表，希望 Agent 自行推断业务逻辑、输入输出、流程和边界。

## 不适用场景

- 只做 AI 概念科普。
- 只写销售话术，不涉及智能体提示词。
- 用户明确要求方案、报价、测试用例或代码实现，此时应按用户要求追加对应交付物。

## 评审重点

- 是否默认只输出一段可直接使用的智能体提示词。
- 是否能从模糊需求中自行推断业务逻辑、工作流、字段和边界。
- 是否避免输出方案表格、交付计划、测试用例等用户没有要求的内容。
- 是否把自动写回、外部系统权限和客户承诺边界写进提示词。
