# Template Skill

This is a template for creating a new skill.

## What to Change

- Rename the directory.
- Update `SKILL.md` frontmatter.
- Update this README.
- Set the first version in `VERSION`.
- Add an entry to `CHANGELOG.md`.
- Add examples and tests if the skill has behavior that can be checked.

## Human Usage

Explain here what this skill does, who maintains it, and what a reviewer should check before release.
